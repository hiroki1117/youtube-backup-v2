# スマホの画面設計

スマホでは、PC の画面を縮めるのではなく、用途に合わせて表示する情報と配置を変える。画面を変更するときは、この方針に合わせる。

## スマホで優先する用途

1. バックアップした動画を探して再生する。
2. 共有された URL を貼り付けて登録する。
3. 処理中の動画の状況を確認する。

一括の管理作業は PC を主な利用環境とする。ただし、削除などの操作はスマホでも再生ページから行える。

## 共通の決まり

| 項目             | 方針                                                                                                                 |
| ---------------- | -------------------------------------------------------------------------------------------------------------------- |
| 配置の切り替え   | `md`（768px）未満をスマホの配置、`md` 以上を PC の配置とする                                                         |
| 操作部分の大きさ | 画面幅ではなく `pointer-coarse` で切り替える。横向きのスマホは `md` 以上の幅になるため                               |
| タップ領域       | タッチ操作では高さ 40px 以上にする                                                                                   |
| 入力欄の文字     | タッチ操作では 16px にする。iOS のフォーカス時の自動ズームを防ぐため                                                 |
| 余白             | 一覧と動画は画面の左右いっぱいに表示し、文字に使える幅を増やす                                                       |
| 画面の高さ       | ページ全体は `dvh`、動画の高さの上限は `svh` を使う。アドレスバーの開閉で動画の高さが変わらないように                |
| 動作確認         | Storybook を 320px、375px、844×390 のタッチ操作と、640px、1024px のマウス操作で確認し、iPhone の Safari でも確認する |

## 画面ごとの方針

| 画面             | PC                                       | スマホ                                                                                                          |
| ---------------- | ---------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| ヘッダ           | 上部に配置                               | スクロールしても上部に固定                                                                                      |
| 動画の登録       | 右下の丸いボタン                         | 同じ。親指が届く位置に置く                                                                                      |
| 動画一覧の行     | 1 行に日付、状態、元サイト、削除を並べる | タイトルを 2 行まで表示し、その下に日付を置く。処理中のときだけ状態を出す。元サイトと削除は再生ページで操作する |
| 動画一覧の操作   | フィルタと並び順を左右に分ける           | 全幅の切り替えと、並び順、更新を 1 行にまとめる                                                                 |
| 再生ページ       | 見出しの下に動画                         | 動画を最上部に左右いっぱいで表示し、その下に見出し、操作、詳細、コメントを置く                                  |
| 動画の高さ       | 画面の 80% まで                          | 縦持ちでは画面の 60% まで。縦長の動画でも見出しとダウンロードが見えるように                                     |
| ダイアログ       | 画面中央                                 | 画面下から出るシート。ボタンは親指が届く下部に大きく置く                                                        |
| 動画の登録の入力 | URL 欄へ自動でフォーカス                 | 自動でフォーカスしない。キーボードがシートを隠さないようにし、「クリップボードから登録」を主な操作にする        |
| 通知             | 右下                                     | 登録ボタンに重ならないよう、その上に全幅で表示                                                                  |

## 採用しなかったもの

- **画面下部のタブバー:** 移動先が動画一覧と検索しかなく、常時表示の領域に見合わない。
- **サムネイル:** API にサムネイルがなく、取得には backend の変更が必要になる。
- **スワイプでの削除:** 誤操作で動画を消すおそれがあるため、再生ページの確認付きの操作に限定する。

## 検索

検索は専用ページ（`/search`）で行う。スマホでは検索語を上部に置き、よく使う期間はチップ 1 回で選べるようにする。結果は動画一覧と同じ行で表示する。結果から開いた再生ページの戻るリンクは、ブラウザの「戻る」と同じ動きで同じ検索結果へ戻る。日付の入力欄は幅が足りない画面では縦に積む。

検索履歴は検索欄のすぐ下に出す。ページを開くと検索欄へフォーカスするため、キーボードが開いても見える位置に置く。結果の表示中は検索欄へフォーカスすると表示し、入力中はその語を含む履歴に絞る。

| 履歴の項目 | 方針                                                                                                                  |
| ---------- | --------------------------------------------------------------------------------------------------------------------- |
| 残す検索   | 語の確定、期間の選択、履歴の選択のうち、結果が 1 件以上あったもの。戻る、再読み込み、共有リンクでは残さない           |
| まとめ方   | 同じ条件は 1 件にまとめて先頭へ移す。語を足す、期間を変えるなど、5 分以内の調整は途中経過を残さず最後の条件だけを残す |
| 期間       | プリセットはプリセットのまま保存し、選んだ日を基準に計算し直す                                                        |
| 表示名     | 語はそのまま、期間は「今年にバックアップ」のように表示する。URL と動画 ID は動画のタイトルと動画 ID で表示する        |
| 削除       | 1 件ずつはすぐに消す。「すべて削除」は 2 回押す。ログアウトでも消す                                                   |
| 上限       | 30 件。保存先はブラウザの localStorage のみで、端末間では共有しない                                                   |
